# Clawdle mark

Original generated artwork for Clawdle, created with the built-in image-generation tool. The transparent master is `clawdle-logo.png`; Tauri's icon generator produces desktop icon sizes. The shared app uses the 256px derivative.

Design prompt:

Create one polished production app icon for Clawdle, a word puzzle game inspired by Claude Code and Wordle. Logo-brand use. A charming compact pixel-art crab like Claude's blocky terminal crab mascot, fused into a Wordle square tile grid: the central crab body is a tight 3 by 2 arrangement of square tiles, with blocky symmetrical raised claws and short pixel legs forming one unmistakable crab silhouette. Two simple dark square eyes sit on the upper body tiles. Use exact Wordle dark-theme green #538d4e, mustard yellow #b59f3b and charcoal #3a3a3c tiles, with warm Claude coral #d97757 only for the two claws and little legs. Bold flat geometric vector-like shapes, crisp straight edges, minimal tiny details, generous clear silhouette, balanced square composition. No letters, no words, no gradients, no glow, no shadows, no mockup, no existing official brand wordmark. Transparent outside the crab silhouette. Fill about 80 percent of a square canvas with generous transparent margin. Must remain legible at 32 pixels. One logo only.

Clawdle is an independent project. This mark combines a pixel crab silhouette with word-puzzle tiles; it is not an official Anthropic or New York Times logo.
